# Plan Index — အဆင့်ဆင့် မြှင့်တင်ထားတဲ့ စာတမ်းများ

ForNyein ရဲ့ အစီအစဉ်ကို **အလွှာ (Layer) လိုက်** တစ်ဆင့်ချင်း မြှင့်တင်ရေးသားနေတာ။ အလွှာတစ်ခုချင်းက အောက်အလွှာကို ပိုအသေးစိတ်ဖြစ်စေ၊ ပိုတိုင်းတာလို့ရစေ။
**ဖတ်စဉ်**: `Plan.md` (မြေပုံ) → L2a (ဦးတည်ချက်) → L2 (သုံးစွဲပုံ) → L3 (လုပ်ငန်းခွဲ) → …

| Layer | ဖိုင် | ဘာအတွက်လဲ | အခြေအနေ |
|---|---|---|---|
| **L1** | [`Plan.md`](../../Plan.md) | မြေပုံ: ရည်ရွယ်ချက်၊ လက်ရှိအခြေအနေ၊ အလုပ်လုပ်နည်း၊ ဖွဲ့စည်းပုံ၊ Timeline spec၊ အဆင့်များ၊ အန္တရာယ်၊ ဆုံးဖြတ်ချက် | ✅ v4 |

**စည်းမျဉ်း**: အလွှာအသစ်ရေးတိုင်း ဒီ INDEX ကို update၊ `Plan.md` ရဲ့ §၂ (အခြေအနေ) ကို အထောက်အထားနဲ့ပဲ ပြင်။ ဒီစာတမ်းတွေ ကွဲလွဲရင် **အောက်အလွှာ (အသေးစိတ်) ကိုမဟုတ်ဘဲ အပေါ်အလွှာ (L1/L2a) ကို အရင်ပြင်**။
