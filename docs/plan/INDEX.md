# Plan Index — အဆင့်ဆင့် မြှင့်တင်ထားတဲ့ စာတမ်းများ

ForNyein ရဲ့ အစီအစဉ်ကို **အလွှာ (Layer) လိုက်** တစ်ဆင့်ချင်း မြှင့်တင်ရေးသားနေတာ။ အလွှာတစ်ခုချင်းက အောက်အလွှာကို ပိုအသေးစိတ်ဖြစ်စေ၊ ပိုတိုင်းတာလို့ရစေ။
**ဖတ်စဉ်**: `Plan.md` (မြေပုံ) → `DECISIONS.md` (ဆုံးဖြတ်ပြီးအရာ) → L2a (ဦးတည်ချက်) → L2 (သုံးစွဲပုံ) → L3 (လုပ်ငန်းခွဲ) → …

> **အခြေအနေ၏ အမှန်တရားရင်းမြစ်**: ဒီ INDEX ရဲ့ ဇယားနဲ့ `DECISIONS.md` က `Plan.md` ရဲ့ §၀ (layer map) နဲ့ §၁၀ (ဆုံးဖြတ်ချက်) ထက် **နောက်ဆုံးဖြစ်** (Plan.md ကို နောက်တစ်ကြိမ်ပြင်တဲ့အခါ ညှိမယ်)။
