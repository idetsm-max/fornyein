# Shortcuts — ForNyein (CapCut-compatible default)

Implemented in `public/v2/main.js` and the Timeline/Player components. `Ctrl` also works as `Cmd` on macOS.

| Key | Action | Status |
|---|---|---|
| Space | Play / pause | ✅ |
| Ctrl+Z | Undo | ✅ |
| Ctrl+Shift+Z / Ctrl+Y | Redo | ✅ |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste clips (lane-safe) | ✅ |
| Ctrl+D | Duplicate selected clip | ✅ |
| Ctrl+B / S | Split selected clip at playhead | ✅ |
| Delete / Backspace | Delete selected clip | ✅ |
| Shift+Delete | Ripple delete | ✅ |
| Right-click clip | Cut · Copy · Paste · Duplicate · Delete · Ripple delete · Split | ✅ |
| Right-click track header | Hide · Lock · Mute (audio) | ✅ |
| Right-click ruler | Paste at playhead · Add text | ✅ |
| Esc | Close context menu | ✅ |
| Drag media tile → timeline | Add clip at drop time | ✅ |
| Drag file → Media panel | Import media | ✅ |
