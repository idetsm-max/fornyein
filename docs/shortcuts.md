# Shortcuts — ForNyein (CapCut-compatible default)

Implemented in `public/v2/main.js` and the Timeline/Player components. `Ctrl` also works as `Cmd` on macOS.

| Key | Action | Status |
|---|---|---|
| Space | Play / pause | ✅ |
| Ctrl+Z | Undo | ✅ |
| Ctrl+Shift+Z / Ctrl+Y | Redo | ✅ |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste clips (lane-safe) | ✅ |
| Ctrl+D | Duplicate selected clip | ✅ |
| Ctrl+B / S | Split selected clip at playhead | ✅ |
| Delete / Backspace | Delete selected clip | ✅ |
| Shift+Delete | Ripple delete | ✅ |
| Right-click clip | Cut · Copy · Paste · Duplicate · Delete · Ripple delete · Split | ✅ |
| Right-click track header | Hide · Lock · Mute/Solo (audio) · Rename · Height · Delete | ✅ |
| Right-click ruler | Paste · Add text · Marker · Delete left/right · Fit | ✅ |
| Esc | Close context menu | ✅ |
| Drag media tile → timeline | Add clip at drop time | ✅ |
| Drag file → Media panel | Import media | ✅ |
| Ctrl+S | Save project | ⬜ planned (M1, T2) |
| Ctrl+E | Export | ⬜ planned (M1, U10) |
| B / V | Razor / select tool | ✅ |
| Shift-drag clip edge | Ripple trim | ✅ |
| Alt-drag clip edge | Roll trim (shared edit point) | ✅ |
| Alt-drag clip body | Slip source | ✅ |
| Ctrl-drag clip body | Slide clip | ✅ |
| N | Snap on / off | ✅ |
| Q / W | Delete left / right of playhead | ✅ |
| N / P | Snap / main-track magnet | 🟡 snap toggle exists, key not bound |
| M | Add marker | ✅ |
| ↑ / ↓ | Previous / next marker | ✅ |
| I / O | Set in / out | ✅ |
| Shift+I / Shift+O | Clear in / out | ✅ |
| Loop button | Loop in–out playback | ✅ |
| Shift+Z | Zoom to fit | ✅ |
| F | Fullscreen preview | ⬜ planned (M1, U7) |
| ? | Shortcut dialog | ⬜ planned (M1, U11) |
| J / K / L | Pause + step back 1 s / pause / play | 🟡 shuttle speeds not yet |
| ← / → | Nudge one frame (Shift = 1 s) | ✅ |
| Home / End | Go to start / end | ✅ |
